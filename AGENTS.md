# AirPods Buddy development guide

Read SKILL.md and doc/README.md first. Source, actual installed version, and public Release are separate. Follow the documentation for Windows connection and audio, privacy logging, design, local transactional build and rollback. Avoid touching other platform work. Real user logs, local settings, secrets, personal paths and raw screenshots must not enter the repository. Do not reset Bluetooth or remove pairings automatically. A successful request is not proof of link, playback or audible sound. Validate changes offline and on real hardware as applicable; report failed and unverified cases. Public Release requires explicit authorization for the specific version and subsequent website/download verification. Prefer local builds.

Current candidate: 1.9.38 (not a public Release). See doc/04 and doc/maintenance-20261125.md.
