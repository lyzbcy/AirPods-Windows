# 01 · 初心与使命

> 读这份文档的时机：需要理解项目为什么存在、为谁做、设计取舍的出发点。

## 初心

捞鱼（lyzbcy）和星星布丁一起做的实用小工具。起因很简单：**Windows 上连
AirPods 太麻烦**——要点开设置、找到设备、点连接，还经常连成低音质的
通话模式（HFP）。macOS 有丝滑的自动切换，Windows 什么都没有。

于是做了这个"小助手"：

- **一键连接 / 一键断开**：双击托盘图标即可，不用进系统设置
- **默认 A2DP+HFP 完整模式**：音质和麦克风都要（可切纯立体声）
- **米白简约风**：奶油色背景、可爱头像、星星布丁元素——工具也可以很温柔
- **常驻托盘**：不占任务栏，开机自启，要用时再唤出

## 使命

1. **零依赖零安装**：单文件 exe，Windows 自带能力做到一切（蓝牙 API 用
   系统的 `Bthprops.cpl`，界面引擎用系统的 WebView2/Edge）
2. **纯本地**：不联网上传任何数据、无广告、无遥测；唯一网络行为是检查
   GitHub 新版本（可在代码里关掉）
3. **开源共享**：MIT 协议，蓝牙核心逻辑致敬上游 ChromuSx 的
   BluetoothDeviceConnector
4. **可持续**：带自动更新系统（GitHub Releases），用户一键升级

## 设计取舍备忘

| 取舍 | 理由 |
|---|---|
| AHK v2 而不是 C#/Electron | 单文件、免运行时、体积 2.4MB、改逻辑快 |
| WebView2 而不是原生 GUI | HTML/CSS 自由度 → 米白简约风 + 动画成本最低 |
| 内嵌网页资源而不是读本地文件 | 单文件分发；代价是 exe 2.4MB、每次构建要内联（见 03） |
| 复用上游蓝牙逻辑而不是重写 | 那套 `Bthprops` 重试状态机是踩过坑的成熟实现 |
