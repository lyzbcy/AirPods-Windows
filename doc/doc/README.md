## 30 秒快速事实

| 事实 | 内容 |
|---|---|
| 这是什么 | Windows 桌面小工具：一键连接/断开 AirPods，米白简约风 UI，常驻托盘 |
| 技术形态 | **AutoHotkey v2 宿主 + WebView2 网页前端**，编译为单文件 `AirPodsBuddy.exe` |
| 核心依赖 | Windows 自带 `Bthprops.cpl` 蓝牙 API（零第三方驱动） |
| 上游来源 | 蓝牙核心逻辑复用自 [ChromuSx/BluetoothDeviceConnector](https://github.com/ChromuSx/BluetoothDeviceConnector)（MIT） |
| 作者 | 捞鱼 & 星星布丁（用爱发电 💕） |
| 当前版本 | v1.2.0（2026-08-19，已部署到本机并验证） |
| 出问题先看哪 | `%LOCALAPPDATA%\BluetoothDeviceConnector\logs\app-YYYY-MM-DD.log` |

## 最常用的三条路径

**「程序白屏/报错了」** → 读 05（先看日志，白屏=IsVisible 坑，报错=看 `[ERROR]` 行）
→ 再读 02 的「WebView2 承载」一节。

**「我要改界面」** → 改 `webui/index.html` → 跑 `webui/build_ui.ps1` 内联资源
→ 按 02 的「编译与部署」重编 exe。

**「我要加功能」** → 读 02 的「JS 桥协议」+「蓝牙核心」，AHK 侧加 `case`，JS 侧加 `rpc()`。
