## 3. 本轮代码与资产

- `LinkVerifyTick` 仅在首/末采样、成功时记录匿名目标和精确端点状态（0/1/2/4/8/-1）；不因日志触发播放、录音或额外扫描。恢复的链接不重复发同一链路请求；保留音频失败一次有界重试；忙、取消和过期操作明确退出。
- “链路未建立”与“播放端点未就绪”分别指向系统蓝牙/声音设置；蓝牙已连接且播放状态欠确认时用户可主动重试播放连接，无需先断开。该动作复用原路径及麦克风偏好；通话状态不显示重试按钮。
- 两套 49 帧精灵：戴耳机、摘耳机逆序、检查失败；断开失败停留佩戴状态。隐藏停表、不重复赋巨大 data URI、静态终态和减少动态效果。暖黄米白静态玻璃、原创耳机品牌图标与 8 个托盘状态研制同源。所有公开载荷只使用生成成品，不保留私有源图地址。
- 日志脱敏、批写与大小轮转；反馈旧内嵌机器人密钥迁移到本机配置，不提交真实密钥。无配置时确认不读日志、不发送；使用手动 GitHub/复制反馈入口。公开版旧密钥可能早已暴露；未来公开发行前需要安全传输设计或所有者轮换密钥（不得在客户端再次内嵌）。

## 5. 老田评审与后续

最关键缺口仍是稳定真机重连与实际听音：不把 KS 接受、合成回归、候选启动或短暂链路恢复冒写成连接稳定。下一步优先保留脱敏真实证据、明确 Windows 原生路径区别；需要物理耳机或用户实际听音时才向所有者求助。原始日志/密钥/私有路径不得进远端，只提交经过内容审计的源文件及脱敏文档。公开 Release 独立授权。
