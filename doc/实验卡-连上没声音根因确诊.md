# 🔬 AirPods「连上没声音」根因实验卡（10 分钟）

> 目的：确诊是不是**配对密钥失效**（系统日志里有 3 次「相互验证失败」指向这个）。
> 做完这个实验，就能决定软件该怎么修。请按顺序做，别跳步。

---

## 第 1 步：手机蓝牙关掉
iPhone/Android 控制中心 → 蓝牙关闭。（排除手机干扰）

## 第 2 步：Windows 删除耳机
设置 → 蓝牙和其他设备 → 找到 AirPods → **删除设备**

## 第 3 步：清注册表残余（管理员）
右键开始菜单 → **终端(管理员)** → 逐行粘贴执行：

```powershell
# 删除设备的注册表残余（设备 MAC 已确认：70ae2aa42b80）
Remove-Item 'HKLM:\SYSTEM\CurrentControlSet\Services\BTHPORT\Parameters\Devices\70ae2aa42b80' -Recurse -Force

# 删除所有适配器下该设备的链路密钥残余（通配，不需要知道适配器 MAC）
Get-ChildItem 'HKLM:\SYSTEM\CurrentControlSet\Services\BTHPORT\Parameters\Keys' -ErrorAction SilentlyContinue | ForEach-Object {
    $p = Join-Path $_.PSPath '70ae2aa42b80'
    if (Test-Path $p) { Remove-Item $p -Recurse -Force; Write-Output "已删除密钥: $p" }
}

# 重启蓝牙服务（让改动生效）
Restart-Service bthserv -Force
```

如果某行报「拒绝访问」→ 重启电脑后再执行一次（bthserv 占用时需要）。

## 第 4 步：重新配对
AirPods 开盖长按背部按钮（指示灯白闪）→ Windows 设置 → 蓝牙 → **添加设备** → 选 AirPods

## 第 5 步：用小助手连接 + 记录结果
点小助手的连接按钮，然后观察三件事，把结果告诉我：

| 观察项 | 结果 |
|---|---|
| A. 声音设置里出现「耳机输出」了吗？ | 是 / 否 |
| B. 耳机里有电脑的声音吗（放个音乐试试）？ | 有 / 没有 |
| C. （可选）事件查看器 → Windows 日志 → 系统，搜 BTHUSB，还有「相互验证失败(事件16)」吗？ | 有 / 没有 / 没找到 |

---

## 结果怎么用
- **A+B 都好** → 根因坐实是密钥失效，我会把「一键修复连接」做进软件（自动引导删设备+清密钥+重配）
- **还是不行** → 排除密钥，转查 A2DP 音频栈，软件走另一条修法
- 无论如何，结果发我，剩下的交给我
