# 视觉与设计规范

现状：稳定；约束来自实测和已批准的设计 ｜ 负责人：项目维护者 ｜ 最后更新时间：2026-11-26

> 读这份文档的时机：改界面、托盘、小精灵、图标或任何说明页之前。共享层面的美术要求在 `E:\共享\tools\软件开发\推广&美化\美化设计.md`，logo 来源规则在同目录 `图标logo.md`。

## 1. 流程：先设计稿，再还原

1. 新的视觉设计先用生图模型出设计稿，所有者批准后再还原，不要直接在成品上试样式。
2. 还原后运行 `python scripts/ui_fixture_shots.py --output <仓库外目录> [--poster]` 无头截图自检。离线测试只管逻辑，不管排版。
3. 合成设备截图归档到 `reference/design/`；真实桌面截图不进仓库。
4. 真机核对（透明轮廓、托盘、动画）要等所有者同意安装之后再做。工作日 9:00–18:30 不在用户桌面弹窗。
5. 改了页面必须重跑 `webui/build_ui.ps1` 再编译，否则 exe 里是旧页面。

## 2. 设计令牌

| 用途 | 值 |
|---|---|
| 主文字 | `#2A241A` |
| 次级文字 | `#93876F` |
| 主黄 / 浅 / 深 | `#FFC53D` / `#FFD24A` / `#E0A800` |
| 深黄文字 | `#B98A00`；淡黄底 `#FFF3C4` |
| 已连接绿 | `#5F9E77`；淡绿底 `#EAF3ED` |
| 警示红 | `#E25B48` |
| 米白底 | `#FFFCF0` 到 `#FFF7DF` 的暖色渐变 |
| 字体 | 系统界面字体，回退到 Microsoft YaHei UI |
| 缓动 | 常规 `cubic-bezier(.25,.1,.25,1)`；弹出 `cubic-bezier(.34,1.56,.64,1)`；入场 `cubic-bezier(.2,.8,.2,1)` |
| 动效原则 | 短、合成器友好、错落入场；`prefers-reduced-motion` 下全部关闭 |

毛玻璃用静态模糊加一次高光，不做持续变化的模糊。图标用线条、圆头、略不规则的「手绘」画法。不要白色原生表头和滚动条，组件跟主题走。界面里需要表情时用 `webui/assets/face_*.png` 里的原创精选表情。

## 3. 主窗口：整窗开盒

- 窗口 560×580，无边框；根窗口透明色键加 WebView2 透明背景，整扇窗就是一只充电盒。
- 合拢态：上盖 105px，底座 328px。展开态：上盖 108px（绕底边后仰），底座 430px。上盖和底座的高度是 1.9.39 为了让失败时的按钮不出窗口调过的，合拢态比例没变。
- 左栏 126px：设备列表、「遇到问题反馈」（一级入口）、管理 / 设置 / 关于。合拢态要能完整显示两副耳机，更长的列表滚动。
- 右侧合拢时只有一个连接按钮；展开后是当前设备、蓝牙链路、播放状态三行，以及重试、断开、诊断。
- 指示灯只有后端读到真实链路才变绿；没有实际链接不能亮绿灯。
- 进度面板出现时隐藏重复的提示行；失败时「打开系统设置」和「遇到问题反馈」并排一行，自救清单默认收起、展开后自动滚入可视区。

## 4. 右下角小精灵

- 四张独立的 7×7 精灵表：`headphones-49`（戴上）、`headphones-fail`（检查耳机）、`headphones-wait`（佩戴后待机）、`headphones-idle`（未佩戴待机），都是 `webui/assets/*.webp`。
- 每格 128px，20fps；196 帧的脚底中心对齐在 x63.04–64.62，基线 y119–120。断开时逆序播放摘下。
- 终态由后端证据决定，动画不冒充连接成功；窗口不可见时停止合成和计时；减少动态效果时停用循环。
- 原始生图和来源登记由所有者本地维护，公开仓库只放生成成品，不放私有路径。

## 5. 托盘

- **图标**：`assets/brand-tray-off.ico`、`brand-tray-on.ico` 和六帧 `brand-tray-loading-0..5.ico`，由 `assets/make_brand_tray_icons.py` 从同一张品牌图生成。程序、窗口、托盘、软件中心和介绍页同源；16px 和 32px 下要目视检查。
- **回调**：只拦截真实托盘图标上的右键（0x404 通知里的 0x205 / 0x7B），250ms 去抖；左键单击、双击不拦截，保留一键连接。
- **悬浮卡**：悬停 600ms 后出现，期间把托盘提示换成空格避免重叠；用真实图标矩形判断指针是否还在图标上，每 100ms 复查，移出即销毁并恢复原提示；不激活窗口。
- **快捷弹层**：`webui/tray.html`，尺寸 300×416 按缩放；共享主窗口的 WebView2 环境，单独创建控制器；隐藏 200ms 后销毁并释放控制器；只有曾经获得过焦点、之后失焦才收起，点弹层外也收起；任何一步失败都回退到原生菜单。
- **状态真值**：宿主只通过 `setTrayState(已连接, 处理中, 详细日志)` 推送；页面里九个动作走固定白名单，一次只派发一个。

## 6. 说明页：一图流

1.9.41 的「降噪 / 通透」功能页采用获批第二版视觉：暖黄米白、四张原创表情、红色安全代价区、绿色正规路径、可展开详细文字；是一条五站式的一图流，应用内弹窗和分享长图共用同一份标记。规则：

- 静态导出显式关闭站点入场动画并固定可见性，避免截图时卡片缺失；详细文字在应用折叠展开，分享图保留五站摘要。
- 内容事实以 [14](14-竞品对标与高级能力路线.md) 为准，设计不能改事实。
- 产品里不点名竞品，不写时间承诺；日期一律用绝对年份。
- 价格和政策类文案会过时，变化时同步改文案并重新导出长图。
- 接手、审核或重做这份说明，先读 [接手简报](../reference/design/noise-explainer-brief.md)。

## 7. 资源与体积

- 页面图片在构建时内联进 HTML，再打进 exe：`index_built.html` 约 860KB。新增图片用 WebP，单张控制在百 KB 级，能复用已内联的图片就不重复嵌入。
- 生图模型产出的设计稿只用于对齐审美；应用内的文字必须是真实文本，可搜索、可修改、任意缩放都清晰。生图的装饰插画可以作为资源嵌入，但要先压到上面的体积。
- 不使用第三方版权素材，不出现 Apple 标志或官方产品图。

### 1.9.43 可交互表面优先

Win10 真机观察到透明色键窗口视觉可见、鼠标却命中后方窗口。主窗口与美化托盘采用不透明米白底，不再用 WinSetTransColor；保留开盒 CSS，但外部留白为米白而非桌面透明。系统托盘右击优先原生菜单，显式美化菜单隐藏后保留控制器最多 60 秒。真实按钮交互优先于透明轮廓；小精灵透明方案不改。本机实际用户点击断开/连接已观察，右击主观延迟待确认。

### 1.9.45 几何与曲率基准

主窗口原生裁剪从实际物理 client rect 创建 GDI rounded region，外框圆角 40 CSS px 对应 GDI 80px 椭圆直径；关闭态保留 y120 到 574，打开态保留 y0 到 574，左右有安全余量，透明位于区域外。打开态因保守裁剪有少量留白，避免重现画面截断。按钮为 lid 的兄弟层，36×36，不继承 3D 变换。外框与内部卡片、面板、按钮共同使用 --curve:40px，由组件大小自动约束。离线几何检测使用 elementFromPoint 五点采样，检查两态 lid/base 均在保守边界内。

### 1.9.46 同心曲率与信息层级

外框 40px 曲率为基准；嵌套面板内半径 = 外半径减去内缩（14px），小按钮再递减 8px，避免大圆角吃掉正文内距。进度正文 14/16px 内边距，长英文、中文允许换行。状态卡片采用图标、微标题、真实状态三层，不伪造数值或事件。美化托盘原生主题 GUI，不再创建第二 WebView。独立实验室双栏主题卡片自绘按钮、选择器、滑杆和开关，无原生白色标题栏和默认滚动条；0 接口禁用控制。

### 1.9.47 合盒极简

合盒左侧保留设备和必要入口，右侧唯一可见元素为居中的连接按钮；不展示标题、版本、状态卡、进度、诊断、提示，不出现右侧滚动条。状态卡布局 display 只在开盒启用。测试真实 render() 后的两设备合盒、按钮命中及开盒长文字。

### 1.9.48 品牌极简与窗口手势

合盒中央保留 Logo 和图形化连接按钮；设备保留名称，连接状态为点，其他次级入口使用图标及悬浮/无障碍名称。反馈仍保留一级明确文字。盒盖空白可拖动，右下角手柄 80%–150% 等比缩放，窗口裁剪与 WebView zoom 同步。无头验证拖动/缩放桥接与按钮互不干扰；真实窗口原生区域测试 80%/120% 并恢复尺寸。

### 1.9.50 小精灵动作反转

佩戴/摘下共用 49 帧同一精灵表；快速取消或重连时保存最近显示帧，反向序列从该格开始。终态仍依后端证据，正常动作播放完进入在场的人物待机；隐藏停止，减少动态效果静止。四套 896×896 素材均与角色资源库回流文件 SHA256 一致。新增两项反转帧序测试。

### 1.9.50 品牌核验补充

候选 ZIP 解出 PE 七尺寸主图标与品牌 ICO 逐资源比对一致；主页面内嵌源图经 128px Lanczos 缩放逐像素匹配，软件中心目录 512px 同源。托盘离线图标 off/on/loading 0–5 按 16/32px 目视核对。此证据不代表旧公开版或 Windows 实时图标缓存已经更新。

### 1.9.53 获批三阶段开盒视觉

所有者确认 [三阶段设计稿](../reference/design/airpods-case-reconnect-approved.png)。合盒保留米白品牌头像、标题及唯一主按钮，lid/base 共用连续外轮廓；展开只用一张状态面板并将断开与重连组成同一个圆角控制区，重试播放连接归入诊断。故障阶段继续保留真实状态、进度、自救入口；状态灯只依实际链路，试听仍由用户确认。
