## 文档规则

- 每份模块文档头部三行：现状、负责人、最后更新时间。
- 超过 300 行就拆分；文档与代码同生命周期，改了设计必须同步文档。
- 进度和待办只写在 `roadmap.md`；每次维护另起一份 `reference/maintenance/` 记录，只写脱敏摘要。
- 正式发布先独立授权、核对准确构建、资产、安装与真机证据；不将用户标识、密钥或未经审计的资料提交远端。
