## 待办（按优先级）

### P0 连接、发版闭环

- [ ] 把 1.9.39 安装到本机并验收：需要所有者同意，夜间不默认替换正在运行的安装。装完核对进程路径、启动版本、exe 哈希，以及安装目录的回退副本是否降到 3 份。
- [ ] 严格五轮冷连接与更多型号验收：需要用户在场并当次授权；目前只有本机 AirPods 的 4 次成功和 1 次实听确认。
- [ ] 对照反馈群的 1.9.24 问题：需所有者先切到对应的企业微信企业，再按授权范围刷新缓存读取；现有缓存里只有四条历史症状。
- [ ] 软件中心 catalog 里 AirPods 小助手仍停在 1.9.21（`publishedVersion` 与 `fallbackRelease`），要同步到 1.9.24；启动器适配严格自查的 4 项失败就是因为这个。
- [ ] 更新器下载线路：本机实测直连 GitHub 8 分钟只收到 4KB，而镜像几秒完成。需要加线路选择，SHA-256 校验保证镜像下载的安全。
- [ ] 公开发布下一版需所有者对该版本的明确授权。发版前先定两件事：公网包里的反馈通道怎么给（不能内嵌密钥），以及正式包图标与页面米白图标不一致。

### P1 历史遗留与竞品能力

- [ ] 降噪 / 通透 / 自适应：必须有内核驱动的 AAP 通道，所有竞品都如此。正规签名的门槛与成本已查清，见 [14 · 第 2 节](14-竞品对标与高级能力路线.md)。**2026-11-26 所有者决定暂缓**，重启时先确认公司主体和微软对商业分发的条款。
- [ ] HFP 优先的连接策略推广到非 AirPods 设备：ToothTray 与上游都是 HFP 在前，但本机没有其他耳机可测。
- [ ] 「禁用此耳机的免提」开关：MagicPods 和 WPods 都有，但在只靠 HFP 引导才能建链的适配器上，关掉免提会让冷连接失去可用路径，必须先在真机上验证再决定做不做。
- [ ] 长时通话与多应用争用麦克风：需要用户在场的真机验收。
- [ ] 高音质耳机麦：依赖 AAP 麦克风流 + 虚拟麦克风驱动 + AAC-ELD 解码，同样需要内核驱动，还涉及专利许可。

### P2 体验与增长

- [ ] BLE 广播解析做电量和入耳检测：不需要驱动，是 AirPodsDesktop 的看家功能；需先核对固件是否加密广播。
- [ ] 界面继续打磨：手绘风窗口按钮、设备图标精修、更多毛玻璃质感。改版时用无头浏览器注入虚构设备截图核对排版。
- [ ] Mac 菜单栏版真机验收。

## 已完成里程碑
