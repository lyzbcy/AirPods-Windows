## 1.9.39 合成设备截图

由无头 Edge 加载构建后的页面并注入虚构设备生成，不代表真机连接成功，不含实际设备名称和桌面内容。

- [合拢态](case-closed-1939-fixture.png)：左栏「遇到问题反馈」是一级入口；两副耳机完整可见，更长列表滚动。
- [展开 · 蓝牙链路未建立](case-linkfail-1939-fixture.png)：两个失败动作并排一行，自救清单默认收起。
- [展开 · 播放端点未就绪](case-audiofail-1939-fixture.png)
- [设置 · 通话音质说明](settings-callquality-1939-fixture.png)
- [快捷托盘菜单](tray-1939-fixture.png)：九项动作，新增「遇到问题反馈」。
- [独立实验室：无兼容接口时控件禁用](aap-lab-beta2-no-driver.png)

为了让失败时的按钮不掉到窗口底边以下，这一版调整了开盖布局：上盖从 126px 收到 108px，底座从 410px 加到 430px，底座内边距收窄；结果面板出现时隐藏重复的提示行和计时行。合拢态比例未变。
