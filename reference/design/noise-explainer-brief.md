## 3. 内容事实：设计不能改

五个站点的说法必须和下面一致。要改说法，先去 docs/14 改事实和来源，再回来同步文案。

| 站点 | 标题 | 要说的事 |
|---|---|---|
| 1 | 这个功能必须靠驱动 | 降噪、通透走苹果私有的控制通道，Windows 自带的蓝牙不向普通程序开放；所有能切降噪的 Windows 软件都要装内核驱动 |
| 2 | Windows 只认微软签名的驱动 | 内核驱动要有微软认可的签名才加载；这个保护是对的，只是把小助手也挡在外面 |
| 3 | 同类软件的办法：让用户拆掉自己的防护 | 两种做法：关 Secure Boot 再开测试模式；用社区签名版。各自的代价见现有文案 |
| 4 | 正规的路：找微软签名 | 公司买 EV 代码签名证书，注册微软硬件开发者计划，由微软签名；用户只需点一下并确认管理员权限 |
| 5 | 现在的状态：暂缓 | 门槛已摸清，条件合适再做；先把免驱动的连接做稳 |

四条硬规则：

- **不点名任何竞品。** 写「同类软件」，不写产品名。
- **不写时间承诺。** 不出现「即将」「下个版本」这类词。
- **日期用绝对年份。** 写「2026 年 4 月」，不写「今年 4 月」。
- **不夸大。** 第 4 站只说用户侧的操作很简单，不说「一定成功」。

会过时的两处：证书价格（现在是官网标价约 ¥4,288–6,888 一年）和微软对这类签名的政策。发现变了就改文案并重新导出长图。

## 4. 设计约束

- **主色调**是黄色和米白色，多用毛玻璃质感。设计令牌见视觉与设计规范。
- **应用内窗口只有 560×580**，弹窗宽 464px、最高约 500px，内容在内部滚动。首屏要让人看到标题和第 1 站。
- **正文不小于 11.5px，小标签不小于 10px**，中文在系统字体下要清楚。
- **图标用手绘风**：线条、圆头、略不规则。现有五枚是芯片、带勾的盾、划掉的盾、证书、沙漏，可以重画但含义要保留。
- **动效**是短促的错落入场；用户开了「减少动态效果」时全部关闭。
- **可以用原创表情**：`webui/assets/` 里的 `face_cheer`、`face_heart`、`face_like`、`face_plead`。不要用别的表情包。
- **不出现 Apple 标志或苹果官方产品图**，也不要用第三方版权素材。

### 生图怎么用

- 生图模型适合做两件事：出一版完整的设计稿给人审，以及产出装饰插画。
- **应用内的文字必须是真实文本。** 不要把整张说明做成一张图片塞进应用，那样文字不能搜索、不能改、缩放会糊。
- 装饰插画可以作为资源嵌入，但要用 WebP，单张控制在百 KB 级，因为图片会内联进 exe。
- 设计稿里如果有文字，还原时以第 3 节的事实文案为准，不要照抄生图里可能出错的字。

## 5. 怎么导出和核对

```powershell
# 1. 先重新生成页面，否则截图是旧的
powershell -NoProfile -ExecutionPolicy Bypass -File webui/build_ui.ps1

# 2. 无头截图：应用内各种状态 + 分享长图（输出目录放在仓库外）
python scripts/ui_fixture_shots.py --output <仓库外的目录> --poster

# 3. 界面测试和全量离线测试
node tests/rpc_test.cjs
python tests/run_suite.py --output <仓库外的目录>
```

长图是两遍渲染：先量内容高度，再按 2.6 倍缩放截图。导出时毛玻璃是关掉的，因为长图背后没有内容，开着只会留下淡色块。
