# 2026-11-26 · 降噪说明一图流

现状：源码 1.9.40 已构建、未安装；本机仍运行 1.9.38；公开正式 1.9.24 ｜ 负责人：项目维护者 ｜ 最后更新时间：2026-11-26

## 需求

所有者决定暂缓驱动路线，并要求在应用内对应的功能页把卡点讲清楚，做成一图流，用于向粉丝说明。

## 实现

- 「降噪 / 通透」弹窗重做为五个站点的竖向一图流：必须靠驱动 → Windows 只认微软签名 → 同类软件让用户拆防护的做法与代价 → 找微软签名的正规路径和费用 → 当前暂缓。一条虚线把站点串起来，每站一枚线条图标和一张毛玻璃卡片，依次错落入场，遵循「减少动态效果」设置。
- 产品内不点名任何竞品，不写时间承诺。实验室的状态行、入口和门控逻辑保持原样。
- 分享长图复用同一份标记：无头 Edge 渲染两遍，先量内容高度，再按 2.6 倍缩放截图，得到 1456×2249 的 PNG。
- 文案事实来自 [14 · 竞品对标](../../docs/14-竞品对标与高级能力路线.md) 记录的官方帮助页和微软文档；证书价格是机构官网标价。

- 离线测试 31 套 / 610 项通过，其中界面测试新增一项：五个站点齐全、关键句存在、不点名竞品、不写时间承诺、实验室按钮仍默认禁用。
- 构建：1.9.40，`dist/build-fd2c8219…`，EXE SHA-256 `B5219E2FBE660FA771FDC86CD5D67A051997A67EBE9F5C79BE1035C41E986AF5`。
- 无头截图核对了应用内弹窗的顶部与底部，以及分享长图，见 [设计归档](../design/README.md)。过程中修正了三处：首个图标不像芯片、长图里毛玻璃的淡色块、底部留白过多。
