# AirPods 小助手 v1.9.50 · Windows 发布候选（未正式发行）

本候选面向想在 Windows 上轻松连接已配对耳机、无需安装额外驱动的用户。正式下载仍是 1.9.24。以下为待确认的发布说明草案；候选构建已安装于维护者本机，尚未获得当前版本正式发行授权。

## 从 1.9.24 到本候选

- 米白与暖黄充电盒式界面：合盒保留 Logo、设备列表、图形化快捷操作和连接按钮，开盒动画展开状态与诊断。可拖动盒盖、从右下角等比缩放。
- 托盘快速菜单与主题弹层、49 帧小精灵；连接、重试、断开区分真实操作阶段；佩戴/摘下快速反向动作从当前帧继续。
- 特定 AirPods 冷连接优先尝试目标 HFP 引导，不默认替换用户麦克风；等待目标立体声播放端点、默认输出和共享播放预检。预检通过不等于实际听到声音。
- 已核实断开后若 Windows 再次报告连接，提示来源未确认，不擅自反复重连或断开。
- 遇到问题反馈作为一级入口，诊断日志匿名处理。仅用户同意附日志且传输已配置时采集快照；未配置反馈通道时可复制反馈内容或使用 GitHub。候选包不内嵌反馈密钥。
- 降噪与高级控制说明解释驱动依赖和当前限制；不将独立实验室当作已实现降噪能力。主程序不安装或替换系统蓝牙驱动。

## 已知问题

- 少数 Windows 蓝牙环境仍可能连接或断开缓慢、断开后链路再次出现、播放端点失活或显示已连接却无声。历史 1.9.41 严格五轮测试前两轮成功，第 3 轮延迟断开读回失败；未执行 1.9.50 严格五轮复测，不声称全通过或已经修复根因。
- 使用耳机麦克风时，Classic 蓝牙可能切换到通话音质；希望保持立体声时，可在通话软件中选择电脑或外接麦克风。无长时通话稳定性保证。
- 降噪、通透、自适应与高级强度控制尚未实现可用于实际耳机的驱动通道。其他耳机型号及 LE-only 设备未完成覆盖验收。

## 遇到问题

在 Windows 声音设置确认目标输出并试听。系统连接持续失败时，按应用提供的手动恢复顺序处理；关开整机蓝牙可能影响其他设备，小助手不会代为操作。请通过反馈入口说明故障及发生阶段，可自行决定是否附脱敏日志。
