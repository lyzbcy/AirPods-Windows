## 最终严格验收结论

最新批次 `five-cycles-release-candidate.json`：第1轮断开、连接均exit0，连接后7秒再次核实通过；第2轮断开exit0，连接尝试及一次音频恢复后仍 `RESULT state=audio_failed link=1`，exit5，后续轮次未执行。P0-02 保持未通过，不把原始失败隐藏为成功。

## v1.9.20 Release 条件复核

- 普通环境（其他设备蓝牙开启）严格第3轮连接失败；用户临时关闭其他设备蓝牙后的同口径复测，第2轮 `link_failed link=0`（一次有界重试后，exit5）。因此 P0-02 仍未通过；没有将初轮通过冒充五轮通过，也未归因手机抢占。
- P1-05 的旧偏好迁移新增缺口：v1.9.19 micOff 真实禁用 HFP，v1.9.20 的同一偏好不再禁用；micOn 却可能因旧 HFP 缺失/被禁用而拿不到 captureId，当前 MicSwitchTick 静默返回。旧稳定模式和录音开启都需明确迁移与验收。
- 软件发布资产名与更新器精确筛选一致，README版本描述已改；165项本地/CI通过不替代上述真机及迁移验收。v1.9.20 未发布，用户常驻安装版仍 v1.9.19。
